
# BRGY-AI - Manual QA Documentation

This repository contains information about my manual software testing contribution to our academic capstone project, BRGY-AI.

## About the Project

BRGY-AI is a Retrieval-Augmented Generation (RAG)-based legal information and document assistance system developed for Barangay 134.

The system aims to help residents access basic legal information, prepare documents, and submit complaints.

Our project includes a mobile application for residents and a web-based administrative system.

[View My 55 Manual Test Cases](BRGY-AI-Manual-Test-Cases.xlsm)

## My Role

My main responsibility in the project was manual software testing.

I created 55 manual test cases to check the system's functionality and compare actual results with expected results.

The goal of the testing was to help identify possible issues and determine whether the features were working as intended.

## What I Worked On

- Preparing manual test cases
- Identifying expected results for different test scenarios
- Checking system functionality
- Comparing actual and expected results
- Documenting observations during testing

## What I Learned

Working on this project helped me understand the importance of software testing and how test cases can be used to evaluate a system.

I also gained experience working with a team and became more familiar with the software development and testing process.

## Note

BRGY-AI is an academic group capstone project. This repository focuses on my personal QA contribution and does not involved any coding of the system.

Testing documents and screenshots will only be included if they are approved for public sharing.
